주의사항

  1. 건물·지형·창 방향을 반영한 직사광 가능 시간입니다. 구름·반사광·실내 채광은 포함하지 않습니다.
  2. 가상 예제 · 서울 위도 / 실제 지형 아님 | 위도 37.5665, 경도 126.978 | UTC+9
  3. Z와 건물 기초 표고는 동일 기준입니다. 관측점은 외벽 바깥에 설정하며, 입력 범위 밖 장애물은 계산되지 않습니다.
  4. 각 건물의 떨어진 거리는, 거주 건물의 중심에서 해당 건물의 중심까지의 거리를 나타냅니다.
  5. 1분 단위 기하학적 태양 위치를 사용합니다. 대기굴절·태양 반지름과 실측 오차는 반영하지 않습니다. 결과는 법적 일조 판정이 아닙니다.
  6. 수정한 배치는 새로고침하면 초기화됩니다. 처음 접속할 때 외부 CDN에서 Python 실행 환경을 내려받습니다.
